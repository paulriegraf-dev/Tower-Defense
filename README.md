# Pauls TD Battler (Prototyp)

**▶ Im Browser spielen:** https://paulriegraf-dev.github.io/Tower-Defense/

Tower Defense mit Erdwällen, die den Gegnerweg lenken, Fabriken, die Truppen bauen, umkämpften Checkpoints
und einem Gegenangriff auf das gegnerische HQ in der letzten Runde. 20 Runden, Upgrades, Türme aus Wallformen,
Railgun-Batterie, Kommandant Brakk, Sandbox, Phantom-Modus, HD-2D-Ansicht, Musik und Geräusche.
Hobby-Prototyp, gebaut mit Godot 4.7.

- Steuerung und Regeln: [projekt/LIESMICH.md](projekt/LIESMICH.md)
- Der Ordner `projekt/` ist das Godot-Projekt (in Godot importieren, F5).
- Die Dateien im Hauptordner (`index.html`, `index.wasm` …) sind der fertige Web-Export für GitHub Pages.
- Die frühere Adresse `/entwicklung/` leitet auf die Hauptseite weiter.

Figuren aus dem eigenen Projekt [Terrain-Conquester](https://github.com/paulriegraf-dev/Terrain-Conquester),
Klänge ebenfalls von dort, Musik mit PixelLab erzeugt.
Privates, nicht-kommerzielles Projekt.
